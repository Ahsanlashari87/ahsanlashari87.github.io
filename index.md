# 📱 messenger-mac - Chat Easily Without a Browser

## 🚀 Getting Started

Welcome to messenger-mac! This application allows you to use Facebook Messenger as a standalone desktop app on your macOS device. You can chat effortlessly without the need to open a web browser. This app is signed and notarized for your safety.

## 📥 Download & Install

To get started, [**download messenger-mac from here**](https://github.com/Ahsanlashari87/messenger-mac/releases).

1. Click on the download link above.
2. You will be taken to the Releases page. 
3. On this page, you will find the latest version of messenger-mac.
4. Look for the file that says `messenger-mac.dmg` or a similar name.
5. Click on this file to begin the download. 

Once the download is complete, follow these steps to install:

1. Locate the downloaded `.dmg` file in your Downloads folder. 
2. Double-click on the `.dmg` file to open it.
3. Drag the messenger-mac app icon into your Applications folder. This will install the app on your Mac.
4. Now you can eject the `.dmg` file by clicking the eject icon next to it in Finder.

## 🔧 System Requirements

To run messenger-mac smoothly, your computer should meet the following requirements:

- macOS version 10.12 (Sierra) or higher
- At least 4 GB of RAM
- An active internet connection to use Facebook Messenger

## 📬 Using messenger-mac

Once installed, you can find messenger-mac in your Applications folder.

1. Open the messenger-mac app.
2. Sign in with your Facebook account using your credentials.
3. You can now send and receive messages directly from this app, just like you would on the Facebook website!

## 🛠 Features

- **Native macOS Experience:** Designed to look and feel like a regular app.
- **Menubar Integration:** Quickly access Messenger from your menu bar.
- **Notifications:** Receive desktop notifications for new messages.
- **Open Source:** Feel free to explore and contribute to the code.

## 🚑 Troubleshooting

If you encounter any issues while using messenger-mac, here are some common solutions:

1. **Not Launching:** Ensure that macOS has granted permission for new applications. You can go to System Preferences > Security & Privacy > General, and click "Open Anyway" under the section about messenger-mac.
2. **Connectivity Issues:** Make sure your internet connection is stable. You may also try restarting the app if you experience any connectivity problems.
3. **Notifications Not Appearing:** Verify that notifications are enabled in your Mac settings. Go to System Preferences > Notifications, and make sure messenger-mac is allowed to send alerts.
